# CPH 100A: Problem Sets, Fall 2026

Coursework and implementations for **CPH 100A / Data C146: Foundations of Computational Precision Health** at UC Berkeley, Fall 2026.

This repository contains my work on the course problem sets, including implementations, experiments, and analyses related to machine learning and deep learning for precision health.

## Repository Structure

| Problem Set | Topic |
|---|---|
| [Problem Set 1](psets/pset1/README.md) | Lung cancer screening with machine learning |
| [Project 2](psets/project2/README.md) | Deep learning for medical image classification and segmentation |

Each problem set directory contains the relevant starter code, implementations, experiments, and documentation.
